# Customer Support Dashboard (Excel)

## Overview

This project is an interactive Customer Support Dashboard built in Microsoft Excel to analyze customer service performance using PivotTables, PivotCharts, and dashboard design techniques.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Data Cleaning
- Formulas (COUNTIF, SUMIF, IF, TRIM)

## Key Performance Indicators (KPIs)

- Total Tickets: 500
- Resolution Rate: 63.80%
- Average Resolution Time: 35.90 hours
- Average Customer Satisfaction: 3.22 / 5
- Urgent Tickets: 134

## Dashboard Visualizations

- Tickets by Category
- Tickets by Priority
- Tickets by Channel
- Average Resolution Time by Category
- Average Customer Satisfaction by Category
- Monthly Ticket Trend

## Key Insights

- Product Information had the highest average resolution time.
- Refund had the lowest average resolution time.
- Phone was the highest-volume support channel.
- Omar Hassan achieved the fastest average resolution time.
- Sarah Ahmed handled the highest number of tickets.
